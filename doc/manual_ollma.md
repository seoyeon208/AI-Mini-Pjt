# Ollama 사용 가이드

설치와 실행은 [프로젝트 README](../README.md#실행)를 참고합니다.
이전 모델의 화면 캡처는 현재 동작과 달라 제외했습니다.

## 질문 예시

| 목적 | 질문 |
|---|---|
| 일반 대화 | 안녕 |
| 상태 조회 | auth-service CPU 사용률 알려줘 |
| 매뉴얼 검색 | CPU 급증 대응 매뉴얼 찾아줘 |
| 복합 분석 | payments-service와 gateway-service 공통 원인을 분석해줘 |

일반 대화는 2B, 복합 분석과 작성은 8B 모델을 사용합니다. 단순 조회는 원문으로 답변합니다.
모니터링 수치는 예시 데이터이며 실제 서비스 관측값이 아닙니다.

## 화면 사용

- 서비스 선택 후 질문을 입력합니다. Enter로 전송하고 Shift+Enter로 줄바꿈합니다.
- 처리 과정과 최종 상태, 분석, 조치, 미확인 사항, 출처를 확인합니다.
- 연결 오류가 나면 원인을 해결한 뒤 질문을 다시 불러와 전송합니다.
- 대화 이력은 로컬 `session.db`에 저장됩니다. 이 파일은 공개하지 않습니다.

현재 화면과 점검 결과는 [브라우저 통합 점검](../evaluation/INTEGRATION-CHECK.md),
모델 평가의 조건과 한계는 [평가 방법](../evaluation/README.md)을 참고합니다.
